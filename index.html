HIL ML Ops agent (personal rebuild)

Personal project · Python · 2026

A rebuild of the Daimler ML Ops POC on synthetic data, so the approach can be shown outside the employer.

  • Gated pipeline: an LLM drafts an ISTQB test-basis model, code derives the test cases, a virtual CAN bench (python-can, simulated ECU with injected faults) runs them, and an LLM drafts the RCA and Jira defects. Every stage is human-approved and bound to a SHA-256 hash.
  • Local-first RAG: hybrid BM25 + vector retrieval over Jira/Confluence Cloud with local Ollama embeddings, tiered LLM routing (Ollama llama3.2, free cloud tiers, GPT-4o mini) under a per-run cost cap; 78 tests.
